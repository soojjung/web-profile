소개

핀테크 기업 두 곳에서 3년간 React·JavaScript 기반 프론트엔드를 개발해 왔습니다. 대출 중개 플랫폼에서는 JWT 자동 갱신, 3계층 권한 관리, XSS 방어를 구현했고, AI 금융 서비스에서는 Toss Payments SDK 연동과 주문·결제·환불 플로우를 맡았습니다. 아울러 재사용 컴포넌트, 배포 자동화, PR 리뷰 프로세스 도입으로 반복되는 작업을 구조적으로 줄였습니다.
2025년부터는 백엔드·AI와 피지컬 AI 로봇 부트캠프를 수료하고 직접 만든 서비스를 운영하고 있습니다. 웹 서비스는 누적 85,000회 진단을 기록했고 App Store에는 앱 2개를 출시했으며, Sentry 장애 모니터링과 접근성 대응을 적용했습니다. 또한 Claude Code에 역할별 서브에이전트와 도메인 규칙을 구성하고, 커밋 품질 게이트를 만들어 AI를 단순 코드 생성 도구가 아닌 설계 검토 파트너로 활용하고 있습니다.
