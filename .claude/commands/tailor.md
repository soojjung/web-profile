`resume-tailoring-strategist` 에이전트를 사용해 마스터 이력서를 특정 채용 공고에 맞춰 재구성하세요.

**입력:** $ARGUMENTS

## 처리 방법

1. **마스터 이력서**와 **채용 공고(JD)** 두 가지를 모두 확보:
   - 파일 경로 → Read
   - URL → WebFetch
   - 본문 → 그대로
   - 둘 중 하나가 없으면 명확히 요청
2. `resume-tailoring-strategist` 에이전트를 Agent 도구로 실행. 프롬프트에 반드시 포함:
   - **마스터 이력서 전체**
   - **JD 전체** (회사명/직무명 포함)
   - 8단계 방법론을 **모두** 수행할 것
   - **절대 사실을 날조/과장/추론하지 말 것** — 누락된 정보는 "gap"으로 표기
   - 허용되는 작업: 순서 재배치, 표현 재작성, 관련성 강조, 잠재 성과 발굴, 진실에 부합하는 ATS 키워드 정렬
   - 언어: JD가 한국어면 한국어로, 영어면 영어로
3. 결과를 받으면:
   - **변경 요약** (어떤 bullet을 어떻게 바꿨고 왜 바꿨는지) 먼저 출력
   - **재구성된 이력서 전문**을 그 아래에 출력
   - **항상 새 파일 `cv-{회사명}.html`을 저장소 루트에 생성** (회사명은 영문 소문자·하이픈, 예: `cv-pinetree.html`). 묻지 말고 바로 만들 것
     - 마스터 이력서 HTML(예: `cv-ko.html`, `cv.html`)을 복사해 구조·스타일·PDF 다운로드(`downloadPdf`, 파일명)를 유지하고 내용만 교체
     - 같은 이름 파일이 이미 있으면 덮어쓰기 전에 사용자에게 확인
     - 생성 후 PDF가 빈 마지막 페이지 없이 나오는지 확인하고 결과 보고
