지원 동기

저는 핀테크 기업 두 곳에서 3년간 React 기반 서비스를 개발했습니다. Toss Payments 결제·환불 플로우와 SSE 스트리밍 챗봇 UI, 50개 이상의 재사용 UI 컴포넌트를 만들며 사용자가 직접 만나는 화면을 맡았습니다. 사용자의 입장에서 흐름을 설계하고 그 결과가 사용자 반응으로 바로 돌아온다는 점은 프론트엔드의 가장 큰 매력이었습니다. 다만 화면에서 발견한 문제의 원인이 데이터나 서버에 있을 때는 직접 고치지 못하고 다른 파트의 작업을 기다려야 했고, 화면만으로는 서비스가 해결하려는 문제 전체를 책임지기 어렵다는 한계를 느꼈습니다. 그래서 2025년에 7개월 과정의 백엔드·AI 부트캠프를 수료하고, LangChain 기반 RAG 파이프라인과 FastAPI 서버, React 화면을 갖춘 정책 상담 챗봇을 직접 만들어 봤습니다. 지금은 웰니스 앱 dwee처럼 기획부터 화면, 데이터 저장, 테스트, 배포까지 서비스 하나를 혼자 개발하고 있습니다. 화면에서 서버와 AI까지 한 흐름으로 만들어 보니, 문제를 처음부터 끝까지 다룰 수 있다는 점이 가장 큰 차이였습니다.

경력직이 아닌 인턴으로 지원한 것은, 지금은 경력을 이어 가는 것보다 이 방향의 실무를 처음부터 제대로 배우는 것이 더 중요하다고 판단했기 때문입니다. 혼자 쌓은 경험을 바탕으로, 실제로 운영되는 시스템에서 팀과 함께 AI를 적용하는 일에 기여하고 싶어 지원했습니다.

문제 해결 경험

대표적인 문제 해결 경험은 신혼부부 정책 상담 챗봇 bbumate입니다. 처음에는 복합 질의 하나에 4.2초가 걸렸고, 색인한 113개 이상의 정책 밖 질문에는 답하지 못했습니다. 단계별 처리 시간을 측정해 보니 검색한 문서를 하나씩 순서대로 평가하는 단계가 응답을 늦추고 있었습니다. 문서 평가를 병렬로 바꾸고, 검색 문서 수(Top-K)를 5개에서 3개로 줄여도 답변 정확도가 체감상 유지되는 것을 확인한 뒤 적용해 처리 시간을 4.2초에서 1.4초로 줄였습니다. 색인 밖 질문에는 RAG → 쿼리 재작성 → 웹 검색 순서의 폴백을 설계해 답하게 했습니다. 정책 안내는 틀리면 사용자가 실제로 손해를 볼 수 있어, 97개 이상의 공식 URL을 정책과 연결해 답변마다 출처 링크를 붙였습니다. 이 경험으로 문서를 많이 넣는다고 답변이 좋아지지는 않으며, 시간·근거처럼 측정할 기준을 먼저 정해야 개선할 지점이 보인다는 것을 배웠습니다.

데이터 기반 성과 분석

직접 운영하는 퍼스널 컬러 진단 서비스는 SEO를 적용해 유입의 83%를 자연 검색에서 확보했고, 누적 85,000회 진단을 기록했습니다. BeHappy에서는 GA4·Mixpanel로 결제까지의 단계별 이탈을 추적해, 주 사용자가 60대 이상이고 접속의 95%가 모바일이라는 점을 확인했습니다. 기술 블로그 글은 조회 4,000회를 넘었습니다. 영상 콘텐츠는 아직 만들어 본 적이 없지만, 결과를 지표로 확인하고 다음 작업에 반영하는 방식은 콘텐츠에도 그대로 적용할 수 있다고 생각합니다.

AI 개발 도구 활용

개인 프로젝트에서는 Claude Code를 역할별 Sub Agent로 나눠 쓰고 있습니다. 웰니스 앱 dwee를 혼자 개발하며 요구사항 정리·구현·단위 테스트·문서 등을 맡는 Sub Agent 7개를 만들었고, AI가 만든 코드는 lint·타입 체크·단위 테스트를 통과해야 커밋되는 /commit 품질 게이트를 거치게 했습니다. 이 구조로 핵심 로직을 단위 테스트 724개로 검증하고, 리팩토링 중 회귀 4건을 미리 막았습니다.

입사 후 계획

입사 후에는 먼저 운영 중인 행정업무 자동화 시스템이 어떤 업무를 어떻게 처리하는지 익히고, 맡은 작업을 정확하게 해내는 것부터 시작하겠습니다. 시스템과 팀의 개발 방식을 이해한 뒤에는 Claude Code와 Sub Agent를 써 온 경험을 살려, 반복되는 작업에서 AI로 생산성을 높일 수 있는 지점을 함께 찾아보고 싶습니다. AI 챗봇·RAG나 콘텐츠 제작처럼 새로 시도하는 업무에서도 빠르게 만들어 보고 결과를 확인하며 개선하겠습니다. 인턴 기간을 마칠 때는 기존 시스템과 AI를 함께 다룰 수 있는 개발자로 한 단계 성장하는 것이 목표입니다.
