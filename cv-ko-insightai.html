소개

핀테크 기업 두 곳에서 3년간 React 기반 서비스를 개발했습니다. 대출 중개 플랫폼에서는 고객·사내 운영·금융 파트너용 3개 포탈과 3계층 권한 관리를 구축했고, AI 금융 서비스에서는 SSE 스트리밍 챗봇 UI와 GA4·Mixpanel 기반 결제 퍼널 분석을 맡았습니다.
2025년부터는 백엔드·AI와 피지컬 AI 로봇 부트캠프를 수료하고 풀스택·AI로 범위를 넓히고 있습니다. Python·FastAPI·LangChain으로 만든 RAG 기반 신혼부부 정책 챗봇 서비스에서는 복합 질의 처리 시간을 4.2초에서 1.4초로 줄였습니다. 직접 운영하는 웹 서비스는 누적 85,000회 진단을 기록했고, App Store에는 앱 2개를 출시했습니다. 개발에는 Claude Code Sub Agent를 역할별로 구성하고 /commit 품질 게이트(lint→테스트→문서 동기화→PR)를 만들어 커밋 전 검증을 자동화해 활용하고 있습니다.
